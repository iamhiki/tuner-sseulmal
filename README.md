# 튜너 쓸래말래 🎸

> 귀 쫑긋! 준비됐어 =^•ω•^=

안녕, 나는 **쓸말이**야. 베이스 줄 맞춰주는 고양이.
오인페(오디오 인터페이스)에 베이스를 꽂고 나를 열어주면 바로 같이 맞출 수 있어. 설치도, 로그인도 필요 없어.

**👉 <https://tuner-sseulmal.vercel.app>**

## 이렇게 쓰면 돼 ( •̀ ω •́ )✧

1. 노트북에 오인페를 꽂고 베이스를 연결한 다음, 위 주소를 열어줘. **크롬**이면 제일 잘 돼.
2. **쓸래! 시작** 을 눌러줘. 브라우저가 소리를 들어도 되냐고 물어보면 허용을 눌러주면 돼.
   - 옆에 있는 **말래…** 버튼은 작은 장난이야. 신경 안 써도 괜찮아.
3. 목록에서 쓰고 있는 오인페를 골라줘. 줄을 튕겼을 때 장치 옆 막대가 움직이면 잘 연결된 거야. 그다음 **이걸로 할래** 를 눌러줘.
4. 줄을 하나씩 튕겨줘. 내가 알려주는 대로 감거나 풀면 돼.
   - 어느 줄인지는 내가 알아서 찾아. 한 줄만 보고 싶으면 아래 **E · A · D · G** 버튼을 눌러서 고정할 수 있어. 한 번 더 누르면 다시 자동으로 돌아가.

4현 표준 튜닝(**E · A · D · G**)이야. 음 이름이랑 Hz, 얼마나 어긋났는지(¢)는 크게 보여줄게. 숫자는 잘 보이게 크게 둘게.

## 내 표정을 보면 알 수 있어 (っ˘ω˘ς )

| 쓸말이가 | 이런 뜻이야 |
|---|---|
| 축 처져서 "줄 좀 감아줘…" | 음이 낮아. 줄 조금 감아줘 |
| 까치발 들고 "너무 팽팽해!" | 음이 높아. 살짝 풀어줘 |
| 만세하면서 "딱 맞았다!" | 완벽해. 다음 줄로 가자 |
| 귀 막고 "으악 너무 커!" | 소리가 너무 세. 오인페 게인 내려줘 |
| 꾸벅꾸벅 "조용하네… 쿨쿨" | 소리가 하나도 안 들어와 |

## 소리가 안 잡히면 (´・ω・｀)

- **케이블을 확인해줘.** 베이스 쪽이랑 오인페 쪽 둘 다 잘 꽂혀 있는지 봐줘.
- **오인페 게인을 조절해줘.** 막대가 너무 낮으면 올리고, 내가 귀를 막고 있으면 내려주면 돼.
- **장치를 확인해줘.** 노트북 마이크가 아니라 오인페를 골라야 해. 노트북 마이크도 베이스 생소리를 주우면 막대가 움직이니까, 막대만 보지 말고 장치 이름도 꼭 확인해줘. 목록에 이름이 비어 있으면 아직 권한이 허용되지 않은 거야. 처음 화면에서 다시 시작해줘.
- **두 줄이 같이 울리면** 나도 헷갈려. 한 줄씩 또렷하게 튕기고, 안 쓰는 줄은 손으로 살짝 막아주면 좋아.
- 오인페가 빠지면 내가 알려줄게. 다시 꽂으면 알아서 이어 들을게. 잘 안 되면 **다시 꽂았어** 를 눌러줘.

지금 베이스가 없다면 주소 뒤에 `?tone`을 붙여서 열어봐 (<https://tuner-sseulmal.vercel.app/?tone>). 장치 목록에 **테스트 톤**이 생기는데, 그걸 고르면 내 표정을 하나씩 구경할 수 있어. 스피커로는 소리가 안 나니까 걱정 마.

## 알아둘 거 ヽ(•̀ω•́ )ゝ

- **연주 소리는 아무 데도 보내지 않아.** 전부 브라우저 안에서만 듣고, 녹음도 안 해.
- 아직 다듬는 중이라 가끔 삐끗할 수 있어. 미리 양해 부탁해.
  - 크롬에서 제일 잘 돼. 사파리랑 파이어폭스는 아직 확인 못 했어.
  - 입력이 두 개인 오인페는 1번·2번 소리가 섞여서 들려. 한쪽에만 꽂으면 막대가 좀 낮게 보일 수 있어. 지금 고치고 있어.
  - 4현 표준 튜닝만 돼. 5현이랑 드롭 D도 준비할게.
- 이상한 점이 보이면 [여기](https://github.com/iamhiki/tuner-sseulmal/issues)에 알려줘. 알려주면 정말 고마워, 열심히 고칠게.
