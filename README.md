# 튜너 쓸래말래 🎸

> 귀 쫑긋! 준비됐어 =^•ω•^=

안녕, 나는 **쓸말이**야. 베이스 줄 맞춰주는 고양이.
오인페(오디오 인터페이스)에 베이스 꽂고 날 열면 끝이야. 설치도, 로그인도 없어.

**👉 <https://tuner-sseulmal.vercel.app>**

## 이렇게 써 ( •̀ ω •́ )✧

1. 노트북에 오인페 꽂고, 베이스 연결하고, 위 주소를 열어. **크롬**이면 제일 좋아.
2. **쓸래! 시작** 을 눌러. 브라우저가 소리 들어도 되냐고 물어보면 허용해줘.
   - 옆에 **말래…** 버튼도 있긴 한데… 눌러볼 수 있으면 눌러봐 ㅋ
3. 목록에서 네 오인페를 골라. 줄 튕겨서 장치 옆 막대가 움직이면 그게 맞는 거야. 그다음 **이걸로 할래** 눌러.
4. 줄 하나씩 튕겨. 내가 알려주는 대로 감거나 풀면 돼.
   - 어느 줄인지는 내가 알아서 찾아. 한 줄만 보고 싶으면 아래 **E · A · D · G** 버튼을 눌러서 고정해. 한 번 더 누르면 다시 자동이야.

4현 표준 튜닝(**E · A · D · G**)이야. 음 이름이랑 Hz, 얼마나 어긋났는지(¢)는 크게 보여줄게. 귀여운 건 나 하나로 충분하니까 숫자는 안 가려.

## 내 표정 보면 알아 (っ˘ω˘ς )

| 쓸말이가 | 이런 뜻이야 |
|---|---|
| 축 처져서 "줄 좀 감아줘…" | 음이 낮아. 줄 조금 감아줘 |
| 까치발 들고 "너무 팽팽해!" | 음이 높아. 살짝 풀어줘 |
| 만세하면서 "딱 맞았다!" | 완벽해. 다음 줄로 가자 |
| 귀 막고 "으악 너무 커!" | 소리가 너무 세. 오인페 게인 내려줘 |
| 꾸벅꾸벅 "조용하네… 쿨쿨" | 소리가 하나도 안 들어와 |

## 소리가 안 잡히면 (´・ω・｀)

- **케이블 꽂았어?** 베이스 쪽, 오인페 쪽 둘 다 봐줘.
- **오인페 게인 돌려봐.** 막대가 너무 낮으면 올리고, 귀 막고 있으면 내려줘.
- **장치 잘 골랐어?** 노트북 마이크 말고 오인페를 골라야 해. 목록에 이름이 비어 있으면 권한을 아직 안 준 거야. 처음부터 다시 눌러줘.
- **두 줄 같이 울리면** 나도 헷갈려. 한 줄씩 또렷하게 튕겨주고, 안 쓰는 줄은 손으로 살짝 막아줘.
- 오인페가 빠지면 내가 알려줄게. 다시 꽂으면 알아서 이어 들을게. 안 되면 **다시 꽂았어** 눌러줘.

베이스가 지금 없으면 주소 뒤에 `?tone`을 붙여서 열어봐 (<https://tuner-sseulmal.vercel.app/?tone>). 장치 목록에 **테스트 톤**이 생기는데, 그거 고르면 내가 어떤 표정 짓는지 다 구경할 수 있어. 스피커로는 소리 안 나.

## 알아둘 거 ヽ(•̀ω•́ )ゝ

- **네 소리는 아무 데도 안 보내.** 전부 네 브라우저 안에서만 듣고 끝이야. 녹음도 안 해.
- 아직 연습 중인 튜너라 가끔 삐끗할 수 있어.
  - 크롬에서 제일 잘 돼. 사파리랑 파이어폭스는 아직 확인 못 했어.
  - 입력이 두 개인 오인페는 1번·2번 소리가 섞여서 들려. 한쪽에만 꽂으면 막대가 좀 낮게 보일 수 있어. 고치는 중이야.
  - 4현 표준 튜닝만 돼. 5현이랑 드롭 D는 나중에.
- 이상한 거 보이면 [여기](https://github.com/iamhiki/tuner-sseulmal/issues)에 알려줘. 꼬리 흔들면서 고칠게.
