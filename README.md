# 튜너 쓸래말래 🎸

> 귀 쫑긋! 준비됐어요 =^•ω•^=

안녕하세요, 저는 **쓸말이**예요. 베이스 줄 맞춰드리는 고양이랍니다.
오인페(오디오 인터페이스)에 베이스를 꽂고 저를 불러주시면 바로 같이 맞춰요. 설치도 로그인도 필요 없어요. 츄르도요. (주시면 감사하고요)

**👉 <https://tuner-sseulmal.vercel.app>**

## 이렇게 쓰시면 돼요 ( •̀ ω •́ )✧

1. 노트북에 오인페를 꽂고 베이스를 연결한 다음, 위 주소를 열어주세요. **크롬**에서 제 귀가 제일 잘 들려요.
2. **쓸래! 시작** 을 눌러주세요. 브라우저가 소리를 들어도 되냐고 물어보면 허용을 꾹 눌러주시면 돼요.
   - 옆에 있는 **말래…** 버튼은 제 작은 장난이에요. 신경 안 쓰셔도 괜찮아요. 냥.
3. 목록에서 쓰시는 오인페를 골라주세요. 줄을 튕겼을 때 장치 옆 막대가 움직이면 잘 연결된 거예요. 그다음 **이걸로 할래요** 를 눌러주세요.
4. 줄을 하나씩 튕겨주세요. 제가 알려드리는 대로 감거나 풀면 끝이에요.
   - 어느 줄인지는 제가 냄새로… 아니 소리로 알아서 찾아요. 한 줄만 보고 싶으시면 아래 **E · A · D · G** 버튼을 눌러서 고정하세요. 한 번 더 누르면 다시 자동이에요.

4현 표준 튜닝(**E · A · D · G**)이에요. 음 이름, Hz, 얼마나 어긋났는지(¢)는 큼직하게 보여드릴게요. 제가 아무리 귀여워도 숫자는 안 가려요.

## 제 표정을 보면 알 수 있어요 (っ˘ω˘ς )

| 쓸말이가 | 이런 뜻이에요 |
|---|---|
| 축 처져서 "축 처졌다냥… 줄 좀 감아주세요" | 음이 낮아요. 줄을 조금 감아주세요 |
| 까치발 들고 "털 곤두섰어요! 살짝 풀어주세요" | 음이 높아요. 살짝 풀어주세요 |
| 만세하면서 "딱 맞았다냥! 골골골" | 완벽해요. 다음 줄로 가요 |
| 귀 막고 "으악 귀 아파요!" | 소리가 너무 세요. 오인페 게인을 내려주세요 |
| 꾸벅꾸벅 "조용하네요… 식빵 굽는 중" | 소리가 하나도 안 들어와요 |

## 소리가 안 잡히면 (´・ω・｀)

- **케이블을 확인해주세요.** 베이스 쪽이랑 오인페 쪽 둘 다 잘 꽂혀 있는지 봐주세요.
- **오인페 게인을 조절해주세요.** 막대가 너무 낮으면 올리고, 제가 귀를 막고 있으면 내려주시면 돼요.
- **장치를 확인해주세요.** 노트북 마이크가 아니라 오인페를 골라야 해요. 노트북 마이크도 베이스 생소리를 주우면 막대가 움직이니까, 막대만 보지 마시고 장치 이름도 꼭 확인해주세요. 목록에 이름이 비어 있으면 아직 권한을 안 주신 거예요. 처음 화면에서 다시 시작해주세요.
- **두 줄이 같이 울리면** 저도 헷갈려서 갸웃해요. 한 줄씩 또렷하게 튕기고, 안 쓰는 줄은 손으로 살짝 막아주세요.
- 오인페가 빠지면 제가 바로 알려드려요. 다시 꽂으시면 알아서 이어 들을게요. 잘 안 되면 **다시 꽂았어요** 를 눌러주세요.

지금 베이스가 없으시면 주소 뒤에 `?tone`을 붙여서 열어보세요 (<https://tuner-sseulmal.vercel.app/?tone>). 장치 목록에 **테스트 톤**이 생기는데, 그걸 고르시면 제 표정을 하나씩 구경하실 수 있어요. 스피커로는 소리가 안 나니까 걱정 마세요.

## 알아두시면 좋아요 ヽ(•̀ω•́ )ゝ

- **연주 소리는 아무 데도 안 보내요.** 전부 브라우저 안에서만 듣고, 녹음도 안 해요. 고양이는 비밀을 잘 지켜요.
- 아직 다듬는 중이라 가끔 삐끗할 수 있어요. 너그럽게 봐주세요.
  - 크롬에서 제일 잘 돼요. 사파리랑 파이어폭스는 아직 확인 못 했어요.
  - 입력이 두 개인 오인페는 1번·2번 소리가 섞여서 들려요. 한쪽에만 꽂으면 막대가 좀 낮게 보일 수 있어요. 지금 고치는 중이에요.
  - 4현 표준 튜닝만 돼요. 5현이랑 드롭 D도 준비할게요.
- 이상한 점이 보이면 [여기](https://github.com/iamhiki/tuner-sseulmal/issues)에 알려주세요. 꼬리 흔들면서 고칠게요.
