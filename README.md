# 튜너쓸말 🎸

> **튜너 쓸래, 말래?** 오디오 인터페이스(오인페)를 꽂으면 바로 쓰는, 하찮고 귀여운 브라우저 베이스 튜너. 다음엔 방구석 베이스 박자 연습 **히키락스타**까지.

설치도, 로그인도, 서버도 없습니다. 브라우저에서 페이지를 열고, 내 오인페를 고르고, 줄을 튕기면 끝.
오디오는 브라우저 안에서만 처리되고 어디에도 전송되지 않습니다.

> 상태: **0단계 완료** (프로젝트 세팅 + 엔진 이식). 아래 로드맵 참고.

---

## 왜 만드나

온라인 튜너는 이미 많지만 대부분 **휴대폰·노트북 마이크** 기준입니다. 베이스를 오인페에 꽂아 연습하는 사람에게는 이런 문제가 남습니다.

- 입력 장치가 여러 개일 때 **어떤 장치를 써야 하는지** 고를 수 없거나 알기 어렵다.
- 소리가 안 잡힐 때 **케이블/게인 문제인지, 튜너 문제인지** 구분이 안 된다.
- **E1(41.2Hz)** 같은 저음에서 바늘이 흔들리거나 한 옥타브 위로 잘못 읽힌다.

튜너쓸말은 이 세 가지를 정면으로 다룹니다. **장치 선택 + 입력 레벨 진단 + 저음 안정 검출**, 그리고 보는 맛이 있는 캐릭터.

## 핵심 기능 (MVP)

| ID | 기능 | 설명 |
|----|------|------|
| F-01 | 입력 권한 | 버튼을 눌러 마이크/입력 권한 요청, 거부 시 다시 허용하는 방법 안내 |
| F-02 | 장치 목록 | `enumerateDevices()`로 오인페 등 `audioinput` 목록 표시 |
| F-03 | 장치 선택 | `deviceId`로 원하는 입력 연결, 바꿀 때 이전 스트림 정리 |
| F-04 | 입력 레벨 | RMS 레벨 미터로 무신호 / 너무 작음 / 적정 / 클리핑 구분 |
| F-05 | 음정 검출 | YIN + FFT 고조파 보정 하이브리드 엔진 (아래 참고) |
| F-06 | 음정 표시 | 음 이름 · 옥타브 · Hz · 센트 편차 |
| F-07 | 튜닝 목표 | 4현 표준 E1 · A1 · D2 · G2, 목표 현 강조 |
| F-08 | 상태 안내 | 신호 없음 · 분석 중 · 신호 불안정 · 권한 거부 · 장치 분리 · 미지원 |

**MVP에서 하지 않는 것:** 계정, 서버, 녹음, 5·6현 프리셋, 모바일 최적화. 메트로놈과 음원 파일 분석은 튜너 이후 박자 연습 탭 **히키락스타**에서 다룹니다 (아래 참고).

## 사용 흐름

1. 튜너쓸말 페이지를 연다.
2. **시작**을 눌러 오디오 입력 권한을 허용한다.
3. 목록에서 내 오인페(예: M-Track Solo)를 고른다.
4. 레벨 미터로 신호가 들어오는지 확인한다. 안 들어오면 캐릭터가 케이블·게인을 먼저 의심해 준다.
5. 한 번에 한 줄씩 튕기고, 센트 편차를 보며 줄을 감는다.

## 엔진: fgnass/tuner 기반

음정 검출 엔진은 [fgnass/tuner](https://github.com/fgnass/tuner) (MIT © Felix Gnass)의 코드를 가져와 사용합니다.

- **YIN**으로 옥타브에 안전한 대략적 주기 추정 → **FFT 고조파 정렬**로 정밀 보정 → A-weighting으로 저역 잡음 영향 감소
- 연속된 검출이 일치할 때만 바늘이 움직이는 **안정도 게이트** (말소리·잡음 무시)
- 센트 단위 **One-Euro 필터**로 바늘 떨림 억제
- 원본에 이미 베이스 프리셋(4현, Drop D, 5현)과 E1·A1 단위 테스트가 있음

**가져올 것 / 직접 만들 것**

| 원본에서 재사용 | 튜너쓸말에서 새로 구현 |
|---|---|
| `src/lib/pitch.ts`, `fft.ts`, `oneEuro.ts`, `notes.ts` 및 테스트 (이식 완료) | 입력 장치 선택(`deviceId`) — 원본은 기본 마이크만 사용 |
| `usePitch.ts`의 오디오 그래프 구성 아이디어 (하이패스 → 로우패스 → Analyser, 8192 샘플) | 입력 레벨 미터, 장치 분리(`devicechange`) 처리 |
| | 실제 적용된 `sampleRate`·track settings 표시 |
| | 캐릭터 UI 전체 |

**라이선스 의무:** MIT이므로 상업적 사용·수정·재배포 모두 가능합니다. 단, 가져온 코드에 원본 저작권 표시와 MIT 전문을 함께 넣어야 합니다 (`THIRD_PARTY_NOTICES.md`). 원본에 포함된 Oswald 폰트는 SIL OFL 1.1이며, 쓰지 않을 계획입니다.

**기술 스택 메모:** 원본은 **Preact + Signals + Vite**입니다. 기획서는 React였지만, 엔진 코드(`src/lib/*`)는 프레임워크와 무관한 순수 TypeScript라 어느 쪽이든 가져올 수 있습니다. 기본 계획은 **Preact + TypeScript + Vite** (원본 훅을 덜 고쳐도 되고 번들이 작음). React가 꼭 필요하면 `preact/compat`로 전환 가능합니다.

## 디자인 방향: "하찮고 귀여운"

디자인은 기능 검증 후 확정하지만, 방향은 이렇게 잡았습니다.

- **주인공 캐릭터 1명**이 튜너 바늘 역할을 한다. 예: 줄감개(페그) 머리를 한 작은 생물 "쓸말이".
  - 음이 낮으면 축 처지고(♭), 높으면 발끝으로 서고(♯), 정확히 맞으면 반짝이며 만세.
  - 신호가 없으면 잠들고, 클리핑이면 귀를 막는다. **상태(F-08)를 표정으로 번역**하는 게 핵심.
- **숫자는 절대 가리지 않는다.** 귀여움은 주변에, Hz·센트는 크게 또렷하게. 튜너는 결국 정확해야 하니까.
- 말투는 짧고 장난스럽게: "줄 좀 감아줘…", "딱 맞았다!", "케이블 꽂았어?"
- 색: 따뜻한 크림 바탕 + 한두 개 포인트 컬러, 굵은 손그림 외곽선. 보라 그라데이션·카드 3개 같은 AI 기본값은 피한다.
- 구현: 캐릭터는 **SVG + CSS 애니메이션**(상태별 포즈 5~6개)으로 시작 → 필요하면 Rive/Lottie로 확장.

## 다음 기능: 히키락스타 · 방구석 베이스 박자 연습

튜너를 배포한 뒤, 같은 웹의 두 번째 탭 **히키락스타**로 박치 탈출용 연습 도구를 붙입니다.

- **내 음원 파일**을 넣으면 브라우저 안에서 BPM·첫 박·비트를 분석해 보여줍니다. 파일은 어디에도 전송되지 않습니다.
- 곡에 맞춘 **메트로놈**을 곡과 함께 재생합니다.
- 노트가 판정선으로 흘러오는 **리듬 UI**. 노트는 쓸말이 발자국이고, 장르 형식만 빌리고 특정 게임은 따라 하지 않습니다.
- **오인페로 들어온 내 연주**를 박자와 비교해 "딱! / 쪼끔 빨라 / 쪼끔 늦어"와 평균 ms로 판정합니다.
- 자동 분석이 틀릴 때를 위한 **비트 수동 보정**(탭 템포, 1박 지정)과 기기별 **지연(싱크) 보정** 화면이 함께 들어갑니다.
- 유튜브 링크 변환은 약관·저작권 문제로 **지원하지 않습니다.**

자세한 명세는 [`docs/PROJECT_PLAN.md` 9장](docs/PROJECT_PLAN.md#9-히키락스타-방구석-베이스-박자-연습-튜너-이후)에 있습니다.
