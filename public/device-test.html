튜너쓸말 · 장치 테스트 🎸

오인페 신호가 브라우저까지 깨끗하게 들어오는지, E1(41.2Hz)이 제대로 읽히는지 확인하는 임시 도구예요. 오디오는 이 브라우저 밖으로 나가지 않아요.

1. 입력 권한

Chrome에서 여는 걸 추천해요. 허용 창이 뜨면 "허용"을 눌러 주세요.

2. 입력 장치

2채널 오인페(M-Track Solo 등)는 베이스가 꽂힌 입력 쪽 채널 막대만 움직여요. 그 채널을 고르면 신호가 반으로 줄지 않아요.

상태연결 안 됨

3. 입력 레벨

신호 없음
-60 dB-40-20-100 dBFS
RMS – dBFS 피크 – dBFS 최근 2초 최대 – dBFS 클리핑 횟수 0

기준: 세게 쳤을 때 최대 피크가 -12 ~ -3 dBFS면 딱 좋아요. -1 dBFS 이상(빨강)이면 오인페 GAIN을 조금 내리세요.

4. 대략적인 음정 (E1 옥타브 확인용)

–
– Hz
–
신뢰도 –

그래프: 최근 8초 동안 읽힌 Hz (로그 눈금). 점선은 E1 41.2 · A1 55 · E2 82.4 · D2 73.4 · G2 98Hz. E1을 쳤는데 점이 82Hz 선에 찍히면 옥타브 오검출이에요.

E1 확인 순서

  1. 오인페 GAIN 노브를 왼쪽 끝(최소)까지 돌리고, 베이스를 INST 입력에 꽂아요.
  2. "시작"을 누르고 권한을 허용한 다음, 장치 목록에서 M-Track(오인페)을 골라요.
  3. 4번 줄(E)을 세게 튕기면서 GAIN을 천천히 올려요. 배지가 적정이 되고, 세게 쳐도 클리핑이 안 뜨는 곳에서 멈춰요.
  4. "E1 기록 시작"을 누르고 4번 줄을 한 번 튕겨 길게 울려요. 결과가 41Hz 근처면 성공, 82Hz 근처면 옥타브 오검출이에요.
  5. 장치 표의 샘플레이트와 결과 줄을 복사해서 알려 주세요.
